## 总体判断

现有资料已经足够开始学习和配置汇川 AI820/AI 系列控制器、InoProShop、EtherCAT、RS485/Modbus 等 PLC 侧基础通信能力，但还不足以保证“所有传感器都能直接由 PLC 完整读取”。

原因是：PLC 手册解决的是 PLC 怎么通信、怎么编程；真正读某个设备，还必须有该设备的通讯协议、寄存器表、EtherCAT 对象字典/ESI 文件、通道映射、采样率配置和标定换算关系。

当前建议路线：

- PLC 适合读取：主轴状态、控制器状态、低频过程量、设备运行/报警、部分采集卡输出的工程量。
- PLC 不适合直接读取：三轴振动高频原始波形、声发射高频原始波形。
- 高频信号建议由专用采集器或上位机软件采集，再导出原始文件或窗口特征，前端/算法端读取摘要特征。

## 设备逐项判断

| 对象 | 现有资料 | PLC 直接读取可行性 | 主要缺口 | 建议路线 |
| --- | --- | --- | --- | --- |
| AI820 / AI 系列控制器 | AI810/AI820/AI830 用户手册、InoProShop 软件/指令/运动控制手册 | PLC 侧资料基本够开始配置 | 实物准确型号、实际接线、工程文件、已使用端口 | 先确认 AI820 是 EtherCAT 主站、Modbus 主站，还是仅作控制平台 |
| M3553C 六维力传感器 | M3553C PDF、六维力选型表 | 不能单独判断，因为传感器一般需通过采集卡读 | 采集器是否已加载标定参数、量程、坐标系、输出信号类型 | 通过 M8229 或 iDAS 读取，优先确认是否已经直接输出 Fx/Fy/Fz/Mx/My/Mz |
| M8229 六维力采集卡 | M8229 用户手册 V2.1、M8229f32 EtherCAT ESI/XML、iDAS 手册 20260525 | 有可能由 PLC 读取，但需看通信方式 | EtherCAT 对象字典/过程数据映射、串口寄存器、通道映射、采样率、力值换算 | 优先先用 iDAS 保存数据；若走 EtherCAT，再基于 ESI/XML 确认 PLC 是否能读取工程量 |
| CA-YD-3EC3001 三轴加速度 | 规格书 | PLC 不直接读传感器本体 | IEPE 接线、YE6275D 通道配置、灵敏度换算 | 通过 YE6275D 采集，不建议接普通 PLC 模拟量 |
| YE6275D 振动采集器 | 用户手册、通讯协议 | 可读取状态或低频摘要；不建议 PLC 读全量高频波形 | 实际导出格式、通信协议细节、软件配置、通道映射、是否能输出摘要特征 | 上位机采原始波形；PLC 只读状态或必要低频特征 |
| 声发射设备 | 目前只有报价模板，缺真实型号手册 | 暂不能判断；大概率不适合 PLC 直接读高频原始数据 | 传感器/前放/采集器型号、采样率、通信协议、导出字段、单位 | 先找声发射设备手册；优先上位机/专用采集系统采集 |
| RBZ-E30-B80 主轴控制器 | 控制器说明书、主轴/浮动资料 | 可行性较高，通常可由 PLC 通过 RS485/Modbus 或 I/O 读取/控制 | 具体 Modbus 寄存器地址、波特率、站号、接线、参数设置 | 优先做 PLC 读取主轴转速/报警/运行状态的试验 |
| SAC2-NP1 电缸/单轴驱动器 | 操作手册、XML | 与传感器主线无关，但后续运动状态可读 | 实际接线、EtherCAT/IO 配置、位置/速度变量 | 后续需要记录进给位置或速度时再接入 |

## 当前还缺的关键资料

### 必须尽快补齐

1. AI820 实物准确型号、端口接线图、当前 PLC 工程文件。
2. M8229 的 PLC 通信资料：已归档 `M8229f32_ethercat_esi.xml`，还需确认 EtherCAT 对象字典/过程数据映射或串口/Modbus 寄存器表，至少要知道 Fx/Fy/Fz/Mx/My/Mz 从哪里读。
3. M3553C 标定配置确认项：确认 M8229/iDAS 是否已加载标定参数并直接输出 Fx/Fy/Fz/Mx/My/Mz；标定报告、坐标系方向、量程和单位作为核对与备查。
4. YE6275D 实际采集软件导出样例，至少包含空载和敲击/接触数据。
5. 声发射设备真实型号、手册、采集软件和导出样例。
6. RBZ-E30-B80 的 Modbus 寄存器地址，尤其是转速、运行状态、报警、负载或电流。

### 做实验前还需要

1. 每个传感器的安装位置和方向。
2. 各设备采样率和时间同步方法。
3. 数据保存格式：原始文件、窗口特征文件、实验记录表。
4. 粗糙度仪型号、测量位置、重复次数和 Ra 标签对应方式。

## 是否可以开始做 PLC 读取

可以开始，但应分层推进：

1. 先做 PLC 与 AI820/InoProShop 的基础连接和在线调试。
2. 再做主轴控制器 RBZ-E30-B80 的 RS485/Modbus 读取，因为这类低频状态最适合 PLC。
3. 再尝试 M8229 六维力采集卡的 PLC 读取，前提是基于 ESI/XML 或寄存器表确认对象字典、过程数据映射和工程量含义。
4. 三轴振动和声发射不要一开始强行走 PLC 全量读取；先用专用采集器/软件采集，再把摘要特征或状态交给 PLC/前端。

## 推荐的近期调试顺序

1. AI820 + InoProShop：建立最小工程，确认能下载、在线监控变量。
2. AI820 + RBZ-E30-B80：读主轴实际转速或报警状态。
3. iDAS + M8229 + M3553C：先不用 PLC，保存六维力空载/加载样例。
4. AI820 + M8229：在确认协议后尝试读取六维力工程量或状态。
5. YE6275D 软件：保存三轴振动空载、主轴空转、接触/敲击样例。
6. 声发射：先补资料，再决定是否只走专用上位机。

## 对前端项目的影响

短期前端不需要等待 PLC 完整接入。只要拿到设备导出的 CSV 或窗口特征表，就可以先做本地回放：

- 原始高频文件保留在 `data/raw/` 或外部数据目录。
- 前端读取窗口级摘要 JSON，例如力 RMS、振动 RMS、主频、声发射能量、主轴转速。
- 后续 PLC 实时通信成熟后，再考虑实时接口。
