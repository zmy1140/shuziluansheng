# YE6275D 三轴加速度数据说明

采集日期：2026-06-08

采集链路：

- 传感器：CA-YD-3EC3001 三向压电加速度传感器
- 采集器：YE6275D，设备 SN `6310126`
- 上位机软件：YE7602
- 连接方式：采集器通过网线直连电脑，以太网地址 `192.168.99.121`
- 电脑有线网卡：`192.168.99.100/24`

采集参数：

- 采样率：`1600 Hz`
- 单位：`m/s^2`
- 灵敏度设置：`10.2 mV/(m/s^2)`，对应传感器 `100 mV/g`
- 通道映射：`CH1 = X轴`，`CH2 = Y轴`，`CH3 = Z轴`
- CSV 数值格式：普通小数，保留 6 位小数，不使用科学计数法

推荐优先使用文件：

- `0608data01_xyz.csv`
- `0608dataqingqiao01_xyz.csv`
- `0608datahuangdong01_xyz.csv`

这些文件的字段统一为：

```csv
sample_index,acc_x_m_s2,acc_y_m_s2,acc_z_m_s2
```

其中 `sample_index` 为样本序号；真实时间可按 `time_s = (sample_index - 1) / 1600` 计算。
